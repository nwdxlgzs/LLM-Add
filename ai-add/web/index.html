输入整条算式后，模型实际如何处理？
默认只把整道算式放进一条 user 消息。网络从 assistant 前缀开始，在全部 261 类词表上连续生成，直到结束 token 或预算用尽。原始区逐字保留生成，诊断信息单列；不会补写 CoT、纠错或拼接答案。独立加法校验仅用于提示对错。旧本机检查点继续按其保存协议加载，并明确标注。
这里的训练，真的更新权重吗？
是。浏览器运行由项目原始纯 C 引擎编译的 WebAssembly，执行反向传播、AdamW、RLOO 与 STE 量化训练。历史记录与本次实验分别展示；没有用历史动画冒充训练。训练在 Web Worker 中执行。浏览器版自动选择 SIMD128 或标量后端，不宣称直接使用原生 AVX512。
FP4 模型为什么包含多种精度？
沿用引擎的模块精度分工：路由专家权重使用 MXFP4，其他矩阵使用 FP8，归一化等参数保持 FP32；实际数量随模型宽度变化。缓存为 FP32，CPU 累加为 FP32。量化的误差会影响生成，QAT 不保证通过。阶段卡显示选择权重的实际精度，训练最后更新仍可下载测试；旧逐列模型的 200/200 不能代表整式自由生成能力。
关闭页面、换设备和导入模型时需要注意什么？
各阶段模型自动保留在当前浏览器本机存储中（浏览器可用时），刷新与重置实验后仍可测试。下载 .aiadd 模型包保留权重、协议和 CoT 设置；下载训练断点另外保留优化器；导入后选择阶段继续，不恢复原始采样位置。.aiadd 包含对话协议和 CoT 设置；.cn 裸文件缺少这些元数据，按旧协议导入。新对话实验应下载模型包。关闭页面前下载模型包更便于备份。任何阶段都可以试题，错误、非法 token 和正确答案都会显示。
这个小模型与 DSV4.1F 的关系是什么？
这是本项目的缩小实现，保留 Causal Encoder-Decoder、CSA2 Full/Reindex/Reuse、SWA、MoE、Engram、mHC 和 RoPE，使用 6/8/10 层、宽度可调且新训练不超过 50 万参数的配置。它是专用小型加法实验模型，不是官方完整尺寸权重或通用对话模型；没有视觉塔。
